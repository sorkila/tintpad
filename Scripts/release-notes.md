- New here: **download `Tintpad.dmg` below**, drag it to Applications, launch. macOS 14+. Or `brew install --cask sorkila/tap/tintpad` (Homebrew asks once to trust the tap).
- Signed with a Developer ID and notarized. sha256 `{{SHA256}}`

<details><summary>What Tintpad is</summary>

Press ⌥⌘Space and a black drop falls out of your Mac's notch with your repos inside. Return opens your terminal at that repo with your coding agent (Claude Code, Codex, any CLI) already running, in the mode you used there last. AGENT and MODE chips say exactly what Return runs, and a mode that skips permissions turns red first. Seven terminals, git worktrees (⌃W), headless dispatch (⌃⏎), frecency search. Free and MIT, local-only, no accounts, nothing to unlock.

</details>
