What it does

Built for the keyboard, hostile to friction.

The agent menu-bar apps watch your usage. Tintpad is the part they forgot — the launcher that actually gets you into the work.

handoff

Your terminal, not ours

Ghostty, iTerm2, kitty, WezTerm, Alacritty, Terminal.app, Warp — auto-detected and opened at the repo with the agent running.

safety

Safe / Default / YOLO

Named run modes map to each agent's flags. Dangerous modes get a coral chip — never a silent footgun.

ranking

Frecency, like zoxide

Your most-used repos rise to the top automatically with continuous half-life decay.

worktrees

Isolated branch in one keystroke

⌃W spins up a git worktree and launches the agent there — parallel work, zero setup.

prompts

Launch with a prompt

Type a one-off prompt or pick from your library; it's handed straight to the agent.

private

Local-only, no accounts

Everything lives in a JSON file on your Mac. The Pro license verifies offline. Nothing phones home — and the core is open source, so you can check.

FAQ

The honest questions.

Isn't this just a shell alias?

For the simplest case, yes. Tintpad adds frecency ranking, run-mode safety, git worktrees, handoff to seven terminals, and zero-config polish — and the core is open source, so read it, extend it, or keep your alias. The free tier means there's no risk to try.

Why not just use Raycast?

Raycast runs things inside Raycast. Tintpad's whole point is handing off to your real terminal, purpose-built for the agentic loop (repos, agents, run modes, worktrees). It's also a one-time purchase, local-only, and native. We'll ship a small Raycast extension too, if that's where you live.

Does it phone home? Do I need an account?

No and no. Everything is a local JSON file. There are no accounts and no telemetry. The Pro license is an Ed25519-signed key verified entirely offline. The core is open source so you can verify all of this.

Why does it want Accessibility permission?

Only for Ghostty, which is single-instance on macOS and can't be told to open a window with a command any other way — so Tintpad opens a window and types the command. Other terminals use lighter Automation. It's optional, scoped to launching, and the code is public.

Is it Electron?

No — native Swift/AppKit + SwiftUI. A few megabytes, instant launch, signed and notarized.

Is it really open source if there's a paid tier?

Open core: the launcher, palette, and terminal-adapter layer are open. Pro unlocks power features (worktrees, dispatch, prompt library, presets) to fund ongoing work. Buy Pro to support it, or run the free core forever.
