WHAT IT DOES

The drop
Black on black, straight out of the housing. No notch? It hangs below the menu bar instead.
Your terminal
Ghostty, iTerm2, kitty, WezTerm, Alacritty, Terminal, or Warp. Tintpad opens yours, it doesn't replace it.
The contract
Two chips say exactly what Return runs. Skipping permissions turns red first, so nobody yolos by accident.
Frecency
The repos you actually use float up, with the agent and mode you used last. ⌘0 does it all again.
Worktrees
One keystroke for a fresh branch checkout with an agent already inside.

QUESTIONS

What if my Mac has no notch?

Same drop, hanging just below the menu bar. The notch only makes it look like the hardware did it.

Isn't this a shell alias?

For one repo and one agent, pretty much. Add frecency, worktrees, seven terminals, and a red chip that asks first, and your alias gets long. Keep it if you like, we won't tell.

Is it really free?

Yes. MIT, open source, no account, no Pro version, and nothing leaves your Mac. If it saves you a morning, buy me a coffee.

Why does macOS ask for permissions?

Blame your terminal. Ghostty can't open a window with a command, so Tintpad types it, and typing needs Accessibility. Terminal and iTerm2 take AppleScript, which needs Automation. kitty, Alacritty, and WezTerm need nothing. Warp has no command API at all, so it opens at the repo and the command waits on your clipboard.
